Project Detail

琥珀と青

青い器と琥珀色の一杯から考えた、架空の中華そば店サイト。

Live Site

Concept

静かな余韻を、器と色で伝える。

架空の中華そば店を想定し、青い器と琥珀色のスープをビジュアルの軸にしました。料理を強く売り込むのではなく、食後に残る印象や店の空気が伝わるよう、余白と短い言葉で構成しています。

Menu

店舗らしさへ、静かに着地する。

縦書きや横スクロールで作った余韻を保ちながら、Menuでは架空店舗としての具体性を足しました。RO FIKAより短めに、カードより少し深く見せる詳細としてまとめています。

Project Detail

RO FIKA

架空の小さな夏のカフェとして設計した1ページサイトです。冷たい飲みものと焼き菓子をそばに、窓辺で静かにひと息つける時間をWeb上で表現しました。

Live Site GitHub

Overview

ひとりで静かに過ごせる、夏のカフェ時間。

ターゲットは、ひとりで静かにカフェ時間を過ごしたい人。短い日本語コピー、淡い夏の色味、窓辺の光を活かしたビジュアルで、気取りすぎず入りやすい空気を目指しました。

Menu / Info

雰囲気だけで終わらせない、カフェとしての安心感。

最初は世界観を重視していましたが、マーケティング視点からMenuに価格帯を追加し、Footer InfoにOpen / Close / Place / Seats / Payment / Instagramを整理しました。「おしゃれさ」だけでなく「行けそう」「入りやすそう」という実用性を少し足しています。

Gallery / Motion

写真の実在感を、静かに残す。

Galleryには実写真を使い、架空サイトでもカフェとしての実在感が出るようにしました。窓まわりにはdata-driftによる控えめな動きを入れていますが、Galleryには動きを付けず、写真の空気感と表示の安定性を優先しています。

Responsive

スマホでも、余白と情報を読みやすく。

スマホ表示では、Heroの印象を保ちつつ、Galleryは2列、Footer Infoは1列で読めるように調整しました。横スクロールを出さず、短い説明とスクリーンショット中心で見せています。

Project Detail

ポラーノワークス

架空の就労継続支援B型事業所の見学案内サイトです。「見学だけでも、大丈夫です。」を中心に、利用を急がせず、本人が自分のペースで見学について相談できる導線を設計しました。

Live Site GitHub

Strategy

決定へ押し込まず、不安をほどく導線。

目的を「利用開始」ではなく「見学前の不安軽減」に置きました。FAQ、見学の流れ、写真で見る道順、相談フォームへと段階的に進めることで、本人には急がせず、支援者には必要な情報を探しやすくしています。

Form Design

見学確定ではなく、相談の入口として設計する。

必須項目は「お名前」と「連絡先」の2つに限定しました。自由記入欄は任意であることを明示し、電話が苦手な人にも配慮して、メール希望者には電話しない約束が見えるようにしています。
